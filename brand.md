## Gradients

Use exactly two gradients. Never stack them or animate them.

### Background gradient

**Light mode:**

```css
--gradient-bg: linear-gradient(135deg, oklch(0.98 0.01 248) 0%, oklch(0.95 0.015 263) 100%);
```

**Dark mode:**

```css
--gradient-bg: linear-gradient(135deg, oklch(0.125 0.02 248) 0%, oklch(0.155 0.025 263) 100%);
```

Use for the hero backdrop, page headers, or one large empty region. The contrast of foreground text remains above 16:1 at both endpoints.

### Accent gradient

**Light mode:**

```css
--gradient-accent: linear-gradient(to right, oklch(0.46 0.18 242) 0%, oklch(0.48 0.18 212) 100%);
```

**Dark mode:**

```css
--gradient-accent: linear-gradient(to right, oklch(0.72 0.18 242) 0%, oklch(0.74 0.18 212) 100%);
```

Use for a hero CTA edge, a data-visualization accent bar, or a single premium badge. Do not place body text on it. Do not use it for destructive or irreversible actions.

The gradients are exposed as Tailwind utilities `bg-brand-bg` and `bg-brand-accent`.

## Tone and voice

### Words to use

Be direct, specific, number-forward, and measured. Prefer verbs and concrete nouns. Explain what an action changes, how much space it recovers, why it is considered safe, and how the result was verified. Use calm language unless data is genuinely at risk.

### Words to avoid

Avoid hype, artificial urgency, emojis, exclamation marks, and claims such as revolutionary, game-changing, effortless, unleash, supercharge, or unlock. Do not call an action safe unless its target and verification method are visible.

### Voice example

> 19.2 GiB free. Five temporary folders removed. Games and personal media were untouched.

## Usage dos and don'ts

**Do:**

- Use semantic CSS variables everywhere. Do not hardcode palette hex values in components.
- Keep a 4 px spacing grid and use whitespace to separate decisions.
- Use IBM Plex Mono with tabular numbers for sizes, percentages, file counts, and paths.
- Distinguish measured facts, AI recommendations, user confirmation, execution, and verification as separate states.
- Show exact targets before destructive actions.
- Test every component in light mode, dark mode, and at 390 px width.
- Reserve red for actual danger, failure, or irreversible actions.

**Don't:**

- Use `transition: all`. Name the properties being animated.
- Stack both gradients on one screen.
- Put body text on the accent gradient.
- Use a radial storage chart when a sorted bar or Pareto view communicates concentration more clearly.
- Hide important sizes, paths, exclusions, or verification results behind hover interactions.
- Describe user files as junk without evidence.
