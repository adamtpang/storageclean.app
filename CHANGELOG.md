# Changelog

All notable changes to storageclean.app are documented here.

## [0.2.0.0] - 2026-08-28

### Added

- A responsive Next.js landing page with light and dark themes.
- An interactive, synthetic storage audit for laptop and external SSD scenarios.
- A visible safety model for audit, explanation, confirmation, action, and verification.
- Automated component tests, type checking, production builds, and restricted CI permissions.

### Changed

- Reframed the Windows product as an in-development desktop app with no premature installer link.
- Replaced machine-derived storage figures with rounded synthetic examples.
- Replaced direct competitor claims with an honest product-direction comparison.

### Security

- Disabled the framework signature header and added MIME-sniffing protection.
- Pinned CI actions to immutable commit hashes.
