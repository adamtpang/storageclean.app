# Storage Clean

Landing page for [storageclean.app](https://storageclean.app).

Storage Clean is an open-source, local-first disk cleanup utility. It scans storage, explains what is taking space, and separates safe cleanup from files that need review.

## Local preview

Open `index.html` in a browser, or serve the folder with any static file server.

## Deploy

This repo is static and deploys directly on Vercel.
