# StorageClean 0.3.0 beta 1

The first working Windows beta turns the landing-page concept into a native desktop scanner.

## What it does

- Scans a selected local or removable drive without changing files.
- Ranks top-level storage usage by size, used-space share, and cumulative share.
- Uses bounded concurrency and streaming enumeration to limit memory pressure.
- Skips reparse points to avoid loops and double counting.
- Reports access errors instead of hiding them.
- Suggests safe next investigations for system data, applications, caches, and user data.
- Exports the measured audit to JSON.
- Installs per user through a normal Windows installer wizard and includes a clean uninstaller.

## Safety boundary

This beta is read-only. It cannot delete, move, compress, uninstall, deduplicate, or modify files.

## Important trust note

The beta is not code-signed yet. Windows SmartScreen may display an unfamiliar-app warning. Broad production distribution remains gated on code signing and signed updates.
